- 2026-05-04: Web-next static regression review (Playwright unavailable) found these flow risks:
  - Ready-check: `useReadyCheck` reads `readyCheckDescriptor` and observer sync, but `useAcceptReadyCheck`/`useDeclineReadyCheck` do not invalidate `readyCheckDescriptor.queryKey`, and `ready-check-store` has no action to reset an accepted/declined/expired store back to `pending` when a new LCU ready-check snapshot arrives. Future ready checks can remain hidden/disabled after the first local accept/decline/expire.
  - Queue/lobby queue status: `queueSearchDescriptor` intentionally uses `['lcu', /lol-matchmaking/v1/search, 'search-state']`, but `useJoinQueue`/`useCancelQueue` only invalidate `['lcu', /lol-matchmaking/v1/search]`. Observer sync may eventually update it, but mutation invalidation misses the descriptor consumed by `useQueue` and lobby dodge-penalty logic.
  - Create lobby: route fetches queue data with descriptors, but query errors and create-lobby mutation errors are not rendered; failed platform config/game queue reads collapse to empty/no queue UI, and POST failure only leaves the button enabled again with no user-facing error. Visible labels `ID:` and queue descriptions/icons are also hardcoded/non-i18n.
  - Champ-select loadout: champion pick/ban, reroll, and bench swap call LCU, but `changeSkin`, `changeRune`, and `changeSpell` only update Zustand selection state. The skin picker, summoner picker, and player settings UI do not submit those changes to LCU. RuneEditor uses direct transport requests for perks and invalidates manually, but has no loading/error state and hardcoded visible labels such as `Mimic Page`, `+`, `-`, and stat shard names.
  - Queue/invites/ready-check mutation failures: queue cancel and invite accept/decline failures resolve false without route-level error feedback; ready-check displays descriptor query errors but not accept/decline mutation failures.
  - Swiftplay: LCU submission uses `useSetQuickplayPlayerSlots` and handles submit errors, but supporting LCU/DDRagon query failures for spells, perk pages, runes, skins, and champions are mostly represented as disabled/empty controls rather than explicit error states.
  - Notifications: `notification-manager.ts` covers Notification API, vibration, queue-pop audio, and iOS audio unlock defensively; no code-level blocker found there.
