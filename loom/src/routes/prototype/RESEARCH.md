# Shoma Layout Research

## Global Layout Structure
- **Header**: Top bar containing the app title ("SHO'MA"), connection status ("Phase:Connected"), and debug toggles ("DBG: OFF").
- **Main Content**: The primary area for the current phase (e.g., Lobby, Ready Check, Champ Select).
- **Social Sidebar/Overlay**: A dedicated section for social features, containing "Friends" and "Chat" tabs, friend groups, and individual friend entries with their status and "Invite" buttons.

## Phase: Lobby
- **Header**: "Lobby" title.
- **Mode Selection**: Displays current mode (e.g., "Normal Draft") and a "Change Mode" button.
- **Action Buttons**: "Find match" button prominently displayed.
- **Party List**: Shows current members (e.g., "Member: JosueGalRe#0001, Owner") and an "Invite" button.
- **Lobby Navigation**: Sub-navigation for "Role Preferences" and "Invites".

## Components Observed
- **Buttons**: Standard action buttons ("Change Mode", "Find match", "Invite").
- **Tabs**: Used in the Social section ("Friends", "Chat").
- **Accordions/Collapsibles**: Used for friend groups ("General 25", "cheny 2").
- **List Items**: Used for party members and friends.

## Visual Hierarchy
- The main action ("Find match") and current state ("Normal Draft") are central.
- Social features are accessible but secondary to the main game flow.
